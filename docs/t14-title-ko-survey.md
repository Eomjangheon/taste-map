# T14 표본 조사 — 한국어 제목 결손율 (2026-09-08)

**목적**: 매핑 테이블의 규모와 방식을 정하기 위한 실측. 명세서 §3.3 이 "TMDB·IGDB는 한국어 제목이
비거나 부정확한 경우가 많다(특히 인디 게임)"고 했는데, 실제로 어느 쪽이 얼마나 비는지 확인한다.

## 방법

- IGDB: `alternative_names.name` 에 한글이 있는지 확인. 대형작 10건 + 인디 10건.
- TMDB: `language=ko-KR` 상세 조회. 원제가 한국어면 그것, 아니면 지역화 제목에 한글이 있으면 그것.
- **id 를 고정했다.** 1차 조사에서 검색 1위를 썼다가 동명이작이 섞여 결손율이 20% 로 잘못 나왔다
  (`Parasite` 검색이 봉준호 영화가 아닌 동명 영화를 물어옴). id 고정 후 0% 로 정정됐다.

## 결과

| 소스 | 표본 | 한국어 제목 없음 | 결손율 |
|---|---|---|---|
| TMDB (영화·드라마) | 15 | 0 | **0%** |
| IGDB 대형작 | 10 | 6 | **60%** |
| IGDB 인디 | 10 | 9 | **90%** |

### TMDB — 결손이 아니라 품질이 문제다

15건 전부 한국어 제목이 있었다. 원제가 한국어인 작품(`기생충`·`올드보이`)은 그대로,
외국 작품은 지역화 제목이 정상적으로 온다(`Interstellar` → `인터스텔라`).

다만 **표기가 지저분한 것이 섞인다.**

```
Severance → '세브란스: 단절' - Severance
```

따옴표와 영문 접미사가 붙어 있다. 즉 TMDB 쪽 보정 대상은 "없는 것"이 아니라 **"있는데 이상한 것"** 이다.
전수 등록이 아니라 눈에 띌 때 고치는 예외 처리로 충분하다.

### IGDB — 사실상 전량 필요하고, 있는 것조차 못 쓴다

결손율 자체도 높지만(대형작 60%, 인디 90% — §3.3 의 "특히 인디 게임" 이 실측으로 확인됐다),
더 중요한 문제는 **있는 값의 성격**이다.

```
O  Portal 2       → 포털 2          (정식)
O  Terraria       → 테라리아         (정식)
O  Cyberpunk 2077 → 사펑            ← 속어
O  Breath of the Wild → 젤다 야숨    ← 속어
O  Dave the Diver → 데더다           ← 속어
```

`alternative_names` 는 유저 투고 별칭 필드라 정식 한국어 제목이 아니다. 20건 중 **정식 제목으로 쓸 수 있는 것은 2건(10%)**.
그대로 `title_ko` 에 넣으면 검색 결과에 "사펑"이 뜬다.

→ **T12 에서 게임의 `title_ko` 를 항상 null 로 둔 판단이 맞았다.** IGDB 에서 한국어 제목을 끌어올 방법은 없다.
게임에 한국어 제목을 붙이는 경로는 이 매핑 테이블이 유일하다.

## 규모 판단

- **영화·드라마: 매핑 거의 불필요.** 예외 보정만. 초기 등록 0건으로 시작해도 된다.
- **게임: 전량 수동.** 다만 카탈로그가 온디맨드로 늘어나므로 전수 등록은 불가능하고 무의미하다.
  **실제로 기록된 게임부터** 채우는 점진 방식이 맞다. MVP 시드 게임 + 소프트 런칭 유저가 기록한 게임이
  1차 대상이고, 현실적 규모는 수십~수백 건이다.

## 매칭(T18·T43)에 주는 함의

§5.3 의 "한국어/영어 제목 교차 대조"는 **게임에서는 이 테이블이 없으면 아예 동작하지 않는다.**
영화·드라마는 TMDB 가 양쪽을 다 주므로 교차 대조가 그냥 된다. 자동 확정률 90% 목표에서
게임 쪽 리스크가 영화·드라마보다 크다는 뜻이다.

## 구현 결정 (2026-09-08)

**별도 테이블을 만들지 않고 `works.title_ko` 를 직접 보정한다.** 외부 ID ↔ 한국어 제목 대응은
works 행(`external_ids` + `title_ko`)이 이미 갖고 있어 새 테이블이 없어도 성립하고, 스키마 변경 절차
없이 오늘 쓸 수 있으며 완료 조건의 "즉시 반영"을 만족한다.

- 운영자 화면: `/admin/title-ko` — 결손 목록 + 입력. 내부용이라 꾸미지 않았다. **인증이 없으므로
  소프트 런칭(T30) 전에 접근 제한을 붙이거나 경로를 제거해야 한다.**
- 재적재가 덮지 않는다: `upsertWorks` 의 backfill 은 비어 있을 때만 채운다. `Half-Life 2` 를 원제로
  다시 검색해도 등록한 `하프라이프 2` 가 유지되는 것을 확인했다.
- 자체 카탈로그 우선 조회를 **게임 검색 경로에만** 붙였다(`searchLocalWorks`). IGDB 는 한국어 질의를
  이해하지 못해 이 단계가 없으면 등록해도 검색되지 않는다. 영화·드라마는 TMDB 가 한국어 질의를
  처리하고 결손율도 0% 라 붙이지 않았다 — 붙였더니 포스터 없는 자체 항목이 앞에 와서 화면만 나빠졌다.

**포기한 것**: 수정 이력·출처가 남지 않는다. 누가 언제 무엇을 고쳤는지 추적하려면 별도 테이블이
필요하다. 운영 규모가 커지면 재검토한다.

**T18·T43 인계**: 매칭 엔진의 한/영 교차 대조는 `searchLocalWorks(term, mediaTypes)` 를 그대로 쓰면 된다.
원제와 한국어 제목 양쪽을 본다.
