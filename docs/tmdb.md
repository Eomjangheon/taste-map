# TMDB 연동 메모 (T12)

키 발급 현황은 팀 문서 `Project_Web/docs/external-apis.md` 가 기준이다. 여기에는 **구현에 필요한 API 사실**만 적는다.

## 환경변수

| 변수 | 용도 | 노출 |
|---|---|---|
| `TMDB_READ_TOKEN` | v4 read access token (Bearer 인증) | 서버 전용 |

`TMDB_API_KEY`(v3)도 발급돼 있지만 코드는 **v4 토큰만** 쓴다. 인증 헤더 하나로 끝나 분기할 이유가 없다.

## 라이선스 의무 — 출처 표기

비상업적 무료 사용의 **조건이 TMDB 출처 표기**다. TMDB 데이터가 보이는 화면에는 출처를 노출한다.
`/catalog/titles` 하단에 문구를 넣어뒀다.

> 로고 이미지는 아직 넣지 않았다. 정식 출시 전에 TMDB 로고 에셋을 추가해야 한다.

수익화·광고·과금을 시작하는 순간 상업용 라이선스로 전환해야 한다(연 $1,788 수준). MVP 는 해당 없음.

## 엔드포인트

| 용도 | 경로 |
|---|---|
| 영화 검색 | `/search/movie?query=&language=ko-KR&include_adult=false` |
| 드라마 검색 | `/search/tv?query=&language=ko-KR&include_adult=false` |
| 시즌 목록 | `/tv/{id}?language=ko-KR` — **시즌은 상세 조회에만 들어 있다** |
| 이미지 설정 | `/configuration` — 이미지 호스트·사이즈 목록 |

레이트리밋은 IGDB 만큼 빡빡하지 않지만, 호출을 직렬화하고 최소 60ms 간격을 둔다.

## 포스터 URL 규칙

```
https://image.tmdb.org/t/p/{size}{poster_path}
```

`size` 는 `w92·w154·w185·w342·w500·w780·original`(2026-09-07 `/configuration` 실측).
`poster_path` 는 **앞에 슬래시가 붙은 형태**(`/abc.jpg`)로 오므로 그대로 이어 붙인다.

**저장하지 않는다.** works 스키마에 포스터 컬럼이 없고 계약에 없는 필드를 임의로 추가하지 않는다(AGENTS.md 금지 규칙 3).
조회 시점에 조립해 내려보내고, 외부 포스터이므로 `next/image` 로 감싸지 않고 `<img>` 로 렌더한다.

> ⚠ **WEB-41(포스터 그리드 뷰) 전에 결정이 필요하다.** B 가 저장된 작품의 포스터를 그리려면 경로가 works 에 있어야 한다.
> 지금 구조에서는 B 가 작품마다 외부 API 를 호출해야 하고, 이는 도메인 경계를 넘는다.

## 한국어 제목 (`title_ko`)

`language=ko-KR` 로 요청하면 번역이 있을 때만 지역화 제목이 오고, **없으면 원제를 그대로 돌려준다.**
그래서 지역화 제목이 원제와 다르고 한글을 포함할 때만 `title_ko` 로 채운다.

- 원제가 한국어인 작품(한국 영화·드라마)은 `canonical_title` 자체가 한국어라 `title_ko` 는 null 이다.
- 다만 **시즌**은 canonical 이 `오징어 게임: Season 1` 형태라 한/영 혼용이 된다. 이때는 원제를 한국어 기준으로 삼아
  `오징어 게임: 시즌 1` 을 `title_ko` 에 넣는다.

## §3.1 동일성 — TV 시즌

- **시즌 = 별개 Work.** 시리즈는 `parent_work_id` 로 그룹핑만 하고 동일성 판단에 쓰지 않는다(§3.2).
- 시즌 식별자는 `external_ids.tmdb_season_id`(TMDB 시즌 id). **시즌 행에 시리즈의 `tmdb` id 를 넣지 않는다** —
  같은 값이 되어 같은 시리즈의 시즌들이 서로를 같은 작품으로 물어버린다.
- 특별편(`season_number = 0`)은 제외한다. 시즌 개념과 맞지 않아 카탈로그 노이즈가 된다.
- **movie id 와 tv id 는 네임스페이스가 다르다.** 같은 숫자가 영화에도 드라마에도 있으므로 중복 대조는
  반드시 `media_type` 과 함께 한다.

## 알려진 한계

- **T9 시드(영화·드라마 37건)에 external_ids 가 비어 있다.** 외부 id 가 없으면 대조할 키가 없어,
  같은 작품을 TMDB 로 검색하면 제목이 같아도 새 행이 생긴다(예: 시드 `Squid Game` ↔ 신규 `오징어 게임`).
  제목 기반 매칭은 매칭 엔진(T43)의 일이므로 여기서 해결하지 않는다. 시드에 tmdb id 를 채우는 편이 근본적이다.
- 동시 요청 경합은 막지 못한다. 근본 해결은 `external_ids` 키별 유니크 인덱스이며 contract.md §5 절차가 필요하다.
